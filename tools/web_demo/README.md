# Web simulator demo content

Public-domain books from [Project Gutenberg](https://www.gutenberg.org/)
(EPUB3 editions with images), bundled into the GitHub Pages simulator by
`tools/build_web.sh`:

- *Alice's Adventures in Wonderland* — Lewis Carroll (ebook #11)
- *The Time Machine* — H. G. Wells (ebook #35)
- *The Adventures of Sherlock Holmes* — Arthur Conan Doyle (ebook #1661)

Each EPUB includes the Project Gutenberg License. Only files listed in
`tools/build_web.sh` are packaged; never put personal books here.
